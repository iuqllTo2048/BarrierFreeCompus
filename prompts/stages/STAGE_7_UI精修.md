# Stage 7 — UI/UX 全面精修

必须使用已安装 UI UX Skill，并优先遵守 `docs/DESIGN_SYSTEM.md` 和项目专属 `barrier-free-ui` Skill。

如果 DESIGN_SYSTEM 未经用户确认，回 Design Gate。

本 Stage 不新增大业务功能。

重点：
- 地图/寻路视觉层级
- 手机/PC
- 管理端信息密度
- Element Plus 二次主题
- 深色模式
- 骨架屏
- 空/错/加载
- 反馈一致
- 路线结果卡片
- 风险/可信度
- 地图 marker/popup/route
- ECharts 统一
- Logo/SVG 基础资产（需要时）
- 可尝试低成本路线绘制动画
- Tab 主流程
- 可见 focus
- label/aria-label
- 风险文字+图标

## Anti AI-slop
逐页检查：
无意义渐变、玻璃泛滥、大圆角泛滥、Bento 泛滥、emoji、发光、巨型 Hero、默认后台模板感、层次弱、移动端仅缩放 PC。

先做 UI review 报告，再做用户确认的修复。
不重写稳定业务逻辑。

完成后停止。
