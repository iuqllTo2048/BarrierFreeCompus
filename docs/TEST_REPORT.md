## 2. 路线算法

- 五种行动方式、三种 Profile、昼夜、避楼梯和权重边界均有覆盖。
- 覆盖坡度、楼梯、宽度、路面、照明、UNKNOWN、软障碍、四类硬阻断、单向、同点、断路和风险降级。
- `YenTopKRouterTest` 验证三条不同无环路线按加权成本排序，以及只有一条真实通路时不复制路线。
- `RouteItineraryServiceTest` 验证途经点分段、相邻坐标去重、距离/时间/楼梯/风险汇总、设施和边 ID 合并，以及任一段不可达时整段失败。
- 固定 20×20 双向网格（400 节点）的核心 A* 基线：P50 413µs、P95 1,003µs、最大 3,034µs；门槛为 P95 < 250,000µs。Top-K 会多次调用 A*，该微基准不等同于完整接口或模型延迟。

## 3. 地图与数据安全

- Testcontainers 空库执行 Flyway V1–V9，验证 PostGIS 表、约束和迁移顺序。
- Formal GeoJSON v2 覆盖六类对象的只读预检、`KEEP_TARGET/OVERWRITE`、双指纹并发保护、导入前快照和审计。
- 备份恢复覆盖列表、恢复预览、执行恢复、409 并发冲突、`USER_REPORT` 障碍保护和业务外键对象保留。
- 统一地图对象删除接口覆盖节点关联道路/历史、建筑关联入口/设施，以及设施关联评分、评论和建议。
- Demo 重置只允许 `is_demo=true`，Formal 请求由服务端拒绝。

## 4. 智能路线助手

- 自动测试固定 `AI_ENABLED=false`，不消耗或伪造外部模型额度。
- 受控 Tool 测试覆盖可信用户/数据集上下文、参数校验、地点候选、调用日志、最近设施、障碍草稿不写正式表和提示词注入拒绝。
- 普通路线及含一个途经点的两段路线均可返回三条不同完整候选；一次用户路线请求只记录一次 `calculateAccessibleRoutes` Tool 调用。
- Provider 失败时保留已经完成的结构化 A* 结果，并返回“智能服务暂时不可用，基础路线规划仍可使用”。

真实 DeepSeek 人工联调曾验证：

- “古茗 → 露天电影院”返回 663 米结构化路线并显示在地图，完整模型轮次约 8,369ms。
- “西苑5栋 → 龙山体育场 → 北苑2号楼A座”正确提取一个途经点，后端拆为两段并返回最短 1034 米、无障碍优先 1503 米、综合 1047 米三条完整候选。
- 默认选中确定性推荐路线；点击路线卡后地图只显示对应的一条折线；继续追问风险时保留结构化路线。

真实 Provider 的模型名、延迟和限流会随部署配置变化，不能作为长期自动化承诺。

## 5. 前端人工验收

- 用户路线页和助手初始隐藏完整校园路网；开关可显示，地图选点无需预先打开路网。
- 规划成功后保留 1–3 张候选卡，地图任一时刻只绘制选中的有效路线。
- 管理端道路折线支持绘制、拖动、增删拐点、撤销、重置、完成和取消。
- 管理端已有设施显示直接删除入口；按当前需求不弹出二次确认。
- 管理端可执行 GeoJSON 导出、导入预检、合并、备份列表、恢复预览和一键恢复。
- 管理员打开根路径进入 `/admin`，普通用户进入 `/user`。

## 6. 安全与部署

- 未登录受保护 API 返回 401，USER 访问管理员接口返回 403。
- Refresh Cookie 使用 HttpOnly、SameSite=Lax；刷新轮换、重放拒绝、退出撤销和禁用用户均有覆盖。
- CSV 对公式起始字符做转义；XSS 内容按文本展示。
- AI 白名单不包含 SQL、Shell、删除、审核、角色或 Demo 重置；写操作只生成草稿。
- `scripts/security-scan.ps1` 最近结果为 `SECURITY_SCAN_OK tracked secrets/private keys: 0`。
- 正式 Compose 使用持久卷；隔离 E2E 使用独立项目和 tmpfs，不操作 8080 的 Formal 数据。

## 7. 已知限制

- Playwright 自动化只覆盖 Microsoft Edge Chromium，未声明 Firefox/WebKit 完整兼容。
- 地点简称仍是有限的代码内置兼容，不是完整的数据驱动模糊检索。
- ECharts 独立分包可能触发 Vite 大包提示，但治理洞察主页面已经按需加载。
- 高德域名白名单、真实 Provider 兼容和移动设备体验仍需在目标部署环境人工复核。
- Demo 和管理员录入数据不等同于实地无障碍认证，路线建议应现场确认。
