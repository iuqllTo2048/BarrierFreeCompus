# USER_GUIDE.md — v1.0 使用手册

本文件用于快速上手；逐按钮、逐流程和比赛演示说明见 [用户与管理员详细使用说明书](USER_ADMIN_MANUAL.md)。

## 1. 登录与角色

打开 `http://localhost:8080`。本地 Demo 用户为 `demo_user / Demo@12345`，管理员为 `demo_admin / Admin@12345`。管理员也可访问用户功能；普通用户不能进入管理接口。

顶栏提供页面导航、浅色/深色切换和退出。移动端通过菜单按钮进入导航；键盘用户可使用 Tab，主要交互保留可见焦点。

## 2. 用户路线规划

1. 进入“路线规划”，选择数据集、起点、终点；也可先点“从地图选择”，再点击地图节点。
2. 选择行动方式：轮椅、拐杖、临时受伤、推车/行李或步行，并选择白天/夜间。
3. 按需要启用避开楼梯、休息点或无障碍卫生间偏好，调整距离、坡度和宽度权重。
4. 点击“规划三类路线”。结果可能合并等价路线，因此卡片数量不保证恒为三条。
5. 对照文字名称、线型、风险标签、成本明细、楼梯/坡度、沿途设施与警告选择路线。轮椅模式始终排除楼梯。
6. 可收藏当前结果；每次成功规划自动写入当前用户的路线历史。

地图路线语义：最短路线为灰色虚线，无障碍优先为深青绿实线，综合路线为蓝绿实线。风险不仅用颜色，也显示文字、图标或线型。

## 3. 出行记录与校园共治

“出行服务”包含五个区域：

- 设施详情：查看位置、楼层、开放状态、来源与可信度；可评分、评论或提交信息纠正/新增设施/维护建议。
- 障碍上报：从地图取坐标，填写类型、标题、描述与预计持续时间。单用户首次上报为待审核且不影响路线。
- 我的上报：跟踪审核状态与可信度。
- 路线历史/收藏：收藏历史中的指定路线，或删除自己的历史和收藏。
- 个人中心：保存默认行动方式、避楼梯和路线权重偏好。

只有管理员审核通过且障碍仍在有效期内时，它才会影响路线。多用户近时空同类上报只会提升待核验可信度，不会绕过审核。

## 4. 智能路线助手

进入“智能助手”，选择数据集和行动方式，可输入：

- `从图书馆到体育与健康中心，轮椅怎么走？`
- `当前校园有哪些生效障碍？`
- `上报图书馆附近道路积水`

页面会展示地点识别、白名单 Tool、路线对比和地图结果。障碍请求只生成“尚未生效”的草稿；点击确认后才调用正常上报 API，并继续等待管理员审核。

AI 未配置时使用确定性本地 Mock；外部模型失败时会提示降级。任何情况下，手工路线规划与 A* 不依赖模型。助手不执行 SQL、Shell、删除、审核、角色修改或 Demo 重置。

## 5. 管理员地图编辑

进入“地图数据”，选择 Demo 数据集后可：

- 从地图或列表选择已有对象；新增/编辑节点和道路，新增建筑、入口、设施、障碍。
- 为道路配置端点、折点、距离、坡度、宽度、路面、照明、风险、方向、楼梯和状态。
- 启用/停用数据集，导出 GeoJSON，或校验并幂等导入 Demo GeoJSON。

导入文件必须是 `FeatureCollection`，匹配数据集 ID，声明 `coordinateSystem=GCJ02`，且道路端点已存在。所有管理写操作进入审计日志。

## 6. 管理员治理与统计

“治理工作台”可审核障碍、处理设施建议、启停用户、查看审计/智能体调用日志和维护运行设置。只有勾选实地核验后，审核通过的上报才能获得 HIGH 可信度。

“治理洞察”按数据集、建筑、日期、设施、障碍和可信度筛选，联动地图、建筑评分、设施分布、障碍趋势、路线风险与数据可信度；可导出当前筛选 CSV。AI 总结关闭或失败时使用规则摘要，不影响数值。

## 7. 安全重置 Demo

管理员在治理工作台点击“安全重置 Demo”后，界面会显示二次确认，明确 Formal 不受影响。确认后：

- 只清理当前 Demo 的评分、评论、建议、路线历史和用户上报；
- 恢复 `DEMO_GENERATED` 建筑、入口、节点、道路、设施与种子障碍状态；
- 保留审计日志；Formal 数据集在服务端会被拒绝。

重置会恢复楼梯绕行、坡度冲突、动态封路、未知数据和设施偏好五类场景。它会改变当前 Demo 数据，演示中只有确实需要回到基线时才执行。

## 8. 推荐演示流程

1. USER 登录，用轮椅规划 `N-02 → N-03`，说明三路线、楼梯硬约束与风险解释。
2. 用户上报障碍；ADMIN 在治理工作台审核通过；回到路线页重新规划，说明动态联动。
3. 展示地图编辑器中的自建道路属性和 GCJ-02 数据边界。
4. 展示治理洞察的地图—评分—审核联动、CSV 和 AI 降级。
5. 展示智能助手的 Tool 进度、A* 结果与“草稿后确认”安全链路。

## 9. 常见问题

- 地图不显示：检查 `.env` 的两个高德变量、域名白名单和 Nginx `/_AMapService`；路线算法仍在后端，但页面地图依赖高德底图。
- 页面 401：访问令牌已失效，请重新登录；刷新 Cookie 只在同一浏览器和正确 Secure 设置下生效。
- AI 限流：等待或更换兼容模型配置；手工路线和统计仍可用。
- 路线只有一两张卡：三 Profile 得到相同边序列时会合并，不是计算缺失。
- 重置按钮不可用/报错：仅管理员且仅 Demo 可执行；Formal 被拒绝是预期安全行为。
