# Stage 7 UI Review 与修复记录

## 审查依据

- `docs/DESIGN_DIRECTION.md`
- `docs/DESIGN_SYSTEM.md`
- 项目专属 `barrier-free-ui` Skill
- 本地 `ui-ux-pro-max` 的地图控件可访问性结果
- 当前 Vue 3、Element Plus、高德地图和 ECharts 实际代码

自动浏览器视觉连接受桌面端内部运行环境故障影响，因此本记录以真实 Vue/CSS、生产构建和 Docker 页面为自动依据，多尺寸视觉效果保留人工验收。

## 发现与处理

| 优先级 | 问题 | Stage 7 处理 |
|---|---|---|
| 高 | 800px 以下主导航直接隐藏 | 增加带当前态、SVG 图标和退出入口的移动导航 |
| 高 | 设施和障碍 Marker 只显示“设/障” | 按业务类型映射项目 SVG，并表达选中、可信度和审核状态 |
| 高 | 主题只跟随系统且地图不响应运行时变化 | 增加持久化主题切换，地图、覆盖物和 ECharts 共用主题源 |
| 中 | 移动路线页仅上下堆叠 PC 面板 | 增加地图下方可按钮展开/收起的路线设置与结果面板 |
| 中 | 语义 Token 存在两套别名和硬编码 | 旧变量统一映射到冻结 Token，补齐 Element Plus 主题变量 |
| 中 | 空态文案与结构不一致 | 增加统一 `UiStatePanel`，先用于历史、收藏和障碍上报 |
| 中 | 正式页面保留 Stage 文案和字符状态图标 | 替换为正式产品文案及统一 SVG 图标 |

## 明确不做

- 不允许管理员任意设置 Marker 颜色和图标；视觉语义由设施/障碍类型统一决定。
- 不新增地图、路线或审核业务规则，不调整 A* 和现有 API。
- 不增加 Tailwind、shadcn、图标库或动画库。
- 不把移动端改成只能拖拽的手势交互。

## 人工验收矩阵

1. 桌面 1440px：用户路线页、智能助手、地图编辑器、治理工作台和治理洞察。
2. 平板 768px：移动导航、地图面板顺序、表格横向可读性。
3. 手机 375px：路线设置/结果展开收起、44px 点击区、无横向页面溢出。
4. 浅色和深色：底图、Marker、风险、可信度、图表、边框和正文层级。
5. 键盘：顶栏、移动导航、路线卡片、表单、折叠面板和图标按钮焦点。
6. 减弱动效：加载条和常规状态过渡不持续动画。
