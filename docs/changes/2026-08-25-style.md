## 改动内容
- 对前端 45 个纯格式文件执行 `prettier --write`：src/ 下组件、服务、类型、状态、测试、配置文件（.prettierrc.json、eslint.config.js、tsconfig.json、vite.config.ts、index.html、package.json 等）。

## 解决什么问题
让 `npm run format:check` 全绿，前后端格式门禁一致；避免功能提交混入大量格式噪音。

## 验证
- `npm run format:check` 通过（All matched files use Prettier code style!）
- typecheck / lint / test / build 不受影响。
