# 提交说明：feat: 用户端起点/终点过滤路网辅助节点

## 提交信息
`feat: 用户端起点/终点过滤路网辅助节点`

## 背景
管理员绘制路网时会自动创建名为「新道路节点」的占位节点，它们只是绘图辅助，不应出现在用户端起点/终点选择里。

## 改动内容
- `UserHomeView.vue`：
  - 起点/终点下拉列表过滤掉 `name` 为「新道路节点」的节点（实时生效，后续新增的同样自动过滤）。
  - 「从地图选择」点击到该类节点时提示"该节点是路网辅助节点，不能作为起点或终点"，不写入起终点。

## 解决什么问题 / 新效果
用户端起终点选择更干净，不会被绘图用的占位节点干扰；辅助节点改名成真实地点后自动变为可选。

## 验证
- 前端 typecheck / lint / 31 Vitest / format / build 通过（Node 22）；Docker 部署后前端 200。

## 注意
- 过滤规则基于节点名称"新道路节点"；如后续辅助节点改用其它命名规则，需同步调整过滤条件。
