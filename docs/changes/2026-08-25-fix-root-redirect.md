# 提交说明：fix: 修复管理员登录后根路径跳转

## 提交信息
`fix: 修复管理员登录后根路径跳转`

## 背景
用户反馈：管理员登录后有时界面显示的是用户端。根因：路由根路径 `/` 固定重定向 `/user`，管理员打开站点根地址会落入用户界面；且应用在会话恢复前就开始导航，重定向函数拿不到角色。

## 改动内容
- `router/index.ts`：根路径改为按角色跳转（管理员 → `/admin`，用户 → `/user`）。
- `main.ts`：先恢复会话，再安装路由并挂载，保证根路径重定向时角色已就绪。

## 解决什么问题
管理员打开站点根地址进入管理端，不再出现"管理员身份却看到用户界面"。

## 验证
- 无头浏览器实测：`demo_admin` 打开 `/` → `/admin`；`demo_user` 打开 `/` → `/user`。
- typecheck / lint / build 通过。
